## Launching Apps
I generally use <kbd>Caps Lock</kbd> + <kbd>first letter</kbd> to launch apps (<kbd>Caps Lock</kbd> is my hyper key). If that shortcut is already taken, I use ⌥ + `first letter` instead or ⌘ + ⌥ + `first letter`.

| App                      |              Shortcut               |
| :----------------------- | :---------------------------------: |
| Affinity                 |          ⌥ + <kbd>A</kbd>           |
| Arc                      | <kbd>Caps Lock</kbd> + <kbd>A</kbd> |

| Discord                  | <kbd>Caps Lock</kbd> + <kbd>D</kbd> |
| Finder                   | <kbd>Caps Lock</kbd> + <kbd>F</kbd> |

| Messages                 | <kbd>Caps Lock</kbd> + <kbd>M</kbd> |
| Microsoft Remote Desktop |        ⌘ + ⌥ + <kbd>M</kbd>         |
| Obsidian                 | <kbd>Caps Lock</kbd> + <kbd>O</kbd> |
| Slack                    |          ⌥ + <kbd>S</kbd>           |
| Spotify                  | <kbd>Caps Lock</kbd> + <kbd>S</kbd> |

## Window Management
I use ⌃ + ⌥ as the window management stem and the most intuitive symbol (to me) for the function. The more basic functions are through MacOS instead because it does smoother animations.

| Action              |         Shortcut         |
| :------------------ | :----------------------: |
| Next Display        | <kbd>Caps Lock</kbd> + → |
| Previous Display    | <kbd>Caps Lock</kbd> + ← |
| Left Half           |        ⌃ + ⌥ + ←         |
| Right Half          |        ⌃ + ⌥ + →         |
| Top Half            |        ⌃ + ⌥ + ↑         |
| Bottom Half         |        ⌃ + ⌥ + ↓         |
| Restore Position    |   ⌃ + ⌥ + <kbd>R</kbd>   |
| Toggle Fullscreen   |   ⌃ + ⌥ + <kbd>F</kbd>   |
| Almost Maximize     |  ⌃ + ⌥  + <kbd>M</kbd>   |
| Make Larger         |  ⌃ + ⌥  + <kbd>=</kbd>   |
| Make Smaller        |   ⌃ + ⌥ + <kbd>-</kbd>   |
| Center Window       |  ⌃ + ⌥ + <kbd>\\</kbd>   |
| Tile Left and Right |      ⌃ + ⌥ + ⇧ + ←       |
| Tile Right and Left |      ⌃ + ⌥ + ⇧ + →       |
| Tile Top and Bottom |      ⌃ + ⌥ + ⇧ + ↑       |
| Tile Bottom and Top |      ⌃ + ⌥ + ⇧ + ↓       |
| First Third         |   ⌃ + ⌥ + <kbd>U</kbd>   |
| Center Third        |   ⌃ + ⌥ + <kbd>I</kbd>   |
| Last Third          |   ⌃ + ⌥ + <kbd>O</kbd>   |
| First Two Thirds    |   ⌃ + ⌥ + <kbd>J</kbd>   |
| Center Two Thirds   |   ⌃ + ⌥ + <kbd>K</kbd>   |
| Last Two Thirds     |   ⌃ + ⌥ + <kbd>L</kbd>   |
